# Phase 4 验证记录

日期：2026-09-30。开发版本：0.4.0.dev0。

## 已验证范围

所有测试数据由临时目录人工生成；模型响应与 HTTP 层使用假客户端或模拟响应，未调用付费 API，未上传真实照片。

- 严格 JSON：重复键、非有限数值、代码块、截断、无效编码、过深结构及长度上限。
- 参数：不接受数字字符串、布尔值、未知/重复目标、额外命令/路径、空方案、越界与额外精度。
- 上下文：只发送规定字段，输出方案保存前检测模型等待期间的 XMP 改动。
- 请求：服务商固定 HTTPS 端点、配置校验、环境变量密钥、拒绝无效头部字符、脱敏错误与不自动重试；OpenAI/DeepSeek 请求结构与结束状态检查。
- 预览：同时指定路径与发送选项才读取，限制服务商支持范围，JPEG/PNG 方向处理、最长边限制、EXIF/PNG 文本元数据剥离。
- 方案：离线查看/应用、摘要绑定、篡改拒绝、过期拒绝、缺失字段/白平衡阻断、独占保存与保存失败清理。
- CLI：请求只保存新方案，已存在输出位置在请求前拒绝；离线应用不需密钥。

本地 304 项测试全部通过，Ruff 通过，语句/分支合并覆盖率 95%。源码包与 wheel 构建、文件清单检查通过；独立安装 wheel 后 304 项测试全部通过。远端 Windows/Linux 验证待本轮推送后补充。

## 尚未验收

服务商、模型名和本机密钥环境变量尚未由用户指定。真实 API 的模型兼容性、生成质量、实际计费及图像建议质量均未验证。没有上传用户的原照片或预览。Phase 1–3 的 ACR 结果不等同于 AI 建议质量验收。

Claude/Gemini 适配、白平衡写入、HSL/曲线/清晰度/去雾及 Phase 5 界面不在本版已实现范围。
