## ACR 实机验收

首次用户截图反馈：曝光仍显示 +0.25。反馈后只读检查显示：源目录 XMP 为 +0.25，测试副本 XMP 仍为 +0.50，没有观察到副本被改回旧值。用户随后确认打开的是源目录的原片，而此前程序仅修改测试副本，这解释了该次截图中的旧曝光值；本次反馈不构成测试副本的 ACR 验收结果。

随后在本地准备有明确测试名称的 `LUMINA_TEST_050.NEF` 及同名 XMP，以便从 ACR 标题确认测试对象。其 RAW 摘要与源文件一致，XMP 读取为 +0.50；这些私人测试文件均被 Git 忽略。

用户打开此副本后确认“可以可以，对的对的”，据此记录 **Camera Raw 全局曝光显示 +0.50 的重开验证通过**。收尾时再次只读检查该副本 XMP，Exposure 仍为 0.50。

验证范围：

- 已确认：NEF 定位 XMP → 读取参数 → 修改曝光 → 保存 XMP → ACR 重新打开显示 +0.50。
- 已通过文件级检查：其他元数据内容保持一致，RAW 字节未变，备份与恢复正确。
- 未单独确认：逐项人工核对其他界面设置，以及 ACR 点击完成、保存关闭后的再次读回。收尾的只读结果不能证明 ACR 执行过保存。
