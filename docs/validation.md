## 自动化测试

运行 `python -m pytest -q`，64 项通过，覆盖：

- 十项参数及数值类型、缺失项、中文/空格路径、扩展名大小写、命名空间前缀变化。
- 属性式与元素式表示、分散在多个顶层 Description 的字段、重复/冲突检测。
- 对嵌套快照、蒙版、曲线、未知元数据、注释及 packet 的保留。
- 曝光绝对赋值、范围/精度、预览、重复设置、备份与恢复。
- 非法数值、旧版/未知版、缺失手动设置、只读文件和 packet、DTD/外部实体、损坏和超限 XML。
- 模拟备份失败、Windows 替换失败、备份期间外部修改、替换后的外部修改。
- 命令行入口、JSON/错误流分离、UTF-8 重定向输出。

测试只使用人工数据，不依赖 Adobe 安装，也不证明 Adobe 显影结果。

## ACR 实机验收

首次用户截图反馈：曝光仍显示 +0.25。反馈后只读检查显示：源目录 XMP 为 +0.25，测试副本 XMP 仍为 +0.50，没有观察到副本被改回旧值。用户随后确认打开的是源目录的原片，而此前程序仅修改测试副本，这解释了该次截图中的旧曝光值；本次反馈不构成测试副本的 ACR 验收结果。

已在本地准备有明确测试名称的 `LUMINA_TEST_050.NEF` 及同名 XMP，以便从 ACR 标题确认测试对象。其 RAW 摘要与源文件一致，XMP 读取为 +0.50；这些私人测试文件均被 Git 忽略。等待用户打开此副本确认实际曝光；不宣称 ACR 验收通过。
