# Phase 2 验证记录

日期：2026-09-30。开发版本：0.2.0.dev0。

## 软件验证

- 解析器覆盖原规范例句、赋值/增减差异、英文与全角输入、单位、范围与精度、重复参数、未知及方向冲突语句。
- 计划计算用非零基线验证 Decimal 运算，未记录字段不补零，结果越界不截断。
- 一批写入要么整体校验通过并替换一次，要么不替换原件；白平衡等不支持项不会被静默跳过。
- 基于同一 XMP 快照计算与写入；过期预览摘要、计算后的外部改动均会停止应用。
- 写入失败后调用方快照保持不变，重试能够正常保存。
- 模拟临时文件/备份 fsync 失败、替换失败及外部修改；不留下被误认为有效的残缺备份。
- 保留全部 Phase 1 回归用例，包括其他元数据与嵌套调整的保留、原字节备份、只读和异常 XML。

当前自动测试：200 项通过；语句与分支合并覆盖率统计为 95%，Ruff 检查通过。

额外边界复核覆盖只读 packet 空格/引号变体、未知或重复状态、XML Base 重定向与冲突 RDF 主体、宿主 Decimal 精度/异常设置、不规范数字和浮点下溢。这些输入均保持可控错误，不修改原件。
